// projeto em destaque

sistema-loja-python-mysql

Sistema de gestão de loja via linha de comando

Registra vendas, calcula descontos e totais, cadastra e consulta funcionários, e gera relatórios de faturamento por data. Toda a persistência é feita em um banco MySQL, com credenciais protegidas por variáveis de ambiente.

relatorios(marca_da_roupa, preco_da_roupa, id_do_atendente, desconto, total_da_compra, data)
funcionarios(id, nomes, nascimento, endereco, sexo, telefone)
  • Cadastro de vendas com validação de entrada (preço, ID, desconto) e cálculo automático do total.
  • Relatório de vendas por data, com soma do lucro total do dia.
  • CRUD de funcionários: cadastro, busca por ID e remoção.
  • Conexão segura com MySQL usando python-dotenv para não expor a senha no código.
Python MySQL mysql-connector python-dotenv
